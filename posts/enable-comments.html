打开评论区

Turning On Comments

2026 年 11 月 1 日Nov 1, 2026阅读约 2 分钟About 4 min read

评论区用的是 giscus，它把留言存进你仓库的 GitHub Discussions。所以不需要任何第三方服务器，也不用注册新账号——留言的人用 GitHub 身份登录就行。

不想用也没关系，先关着。每篇文章底部的「写信给我」一直都在。

三个前提

  1. 仓库是 Public
  2. 仓库开启了 Discussions
  3. 装了 giscus App

前两个在仓库的 Settings → General → Features 里：勾上 Discussions，仓库顶部会多一个 Discussions 标签。

第三个：打开 https://github.com/apps/giscus，Install，只授权你的博客仓库。

拿两个 ID

打开 https://giscus.app/zh-CN：

  • Repository 填 你的用户名/仓库名
  • 填对了下面会出现一个绿色的对勾
  • Discussion 分类选 Announcements
  • 页面 ↔ Discussions 映射：随便选，编辑器会用文章 slug 自己覆盖
  • 主题也不用管，它跟随你的明暗切换

往下滑到底，会有一段代码，里面有两行是关键：

data-repo-id="R_kgDO..."
data-category-id="DIC_kwDO..."

填进设置

编辑器 → 设置 → 评论（giscus）：

  • 勾上「在文章底部显示评论区」
  • 评论仓库留空（自动用本站仓库）
  • 仓库 ID：R_kgDO...
  • 分类名：Announcements
  • 分类 ID：DIC_kwDO...

保存，发布一次。

怎么验证成功

打开任意一篇文章，正文底部会出现「留言」区块。第一次有人留言时，你的仓库 Discussions 里会自动多出一条讨论，标题就是文章 slug。

如果整块不显示：先检查两个 ID 是否都填了（缺一个就不渲染）、开关是否保存、以及这次有没有发布成功。

几个说明

  • 评论只在文章页出现，首页和归档页没有
  • 每篇文章对应一条独立讨论，按 slug 匹配，所以换文件名不会丢评论
  • 读者可以选表情、回复楼中楼，都是 giscus 自带的能力
  • 评论是公开的，和仓库一样所有人可见

Comments run on giscus, which stores them in your repository's GitHub Discussions. No third-party server, no new account — readers just sign in with GitHub.

Don't want them? Leave it off. The "email me" button at the bottom of every post never goes away.

Three prerequisites

  1. The repo is Public
  2. Discussions is enabled
  3. The giscus App is installed

The first two live in Settings → General → Features: tick Discussions and a Discussions tab appears at the top of the repo.

Third: open https://github.com/apps/giscus, Install, and authorize only your blog repo.

Get two IDs

Open https://giscus.app:

  • Repository: yourname/repo
  • A green check appears if it's valid
  • Discussion category: Announcements
  • Page ↔ Discussions mapping: anything — the editor overrides it with the post slug
  • Theme: ignore, it follows the site's dark mode

Scroll to the end and you'll get a snippet with two important lines:

data-repo-id="R_kgDO..."
data-category-id="DIC_kwDO..."

Fill in settings

Editor → 设置 → 评论（giscus）:

  • Tick "在文章底部显示评论区"
  • Leave the repo field empty (uses the site's own repo)
  • Repo ID, category name, category ID as above

Save, then publish once.

How to verify

Open any post — a comments block appears below the body. The first time someone comments, a discussion shows up in your repo, titled with the post slug.

If nothing renders: check that both IDs are filled (one missing hides the block), that the toggle is saved, and that the publish actually succeeded.

Notes

  • Comments appear on post pages only, not on home or archive
  • One discussion per post, matched by slug, so renaming files won't orphan them
  • Reactions and threaded replies come free with giscus
  • Comments are public, just like the repo
