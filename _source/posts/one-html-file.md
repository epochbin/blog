这个博客现在只有一个文件。

没有数据库，没有后台，没有构建流程。打开它，写，点发布，几秒钟后 GitHub Pages 上就多了一页。

## 为什么这么折腾

我用过不少博客系统。它们大多要求我先变成一个运维：装环境、配数据库、定期升级、处理证书。

后来我想明白一件事：我要的只是「把想法排成好看的版面」，剩下的都不该由我操心。

于是就有了这个东西。

## 它怎么工作

正文用 Markdown 写，存在浏览器里。发布时整站被重新生成一遍，只把有变化的文件推到仓库。

```
$ git status
nothing to commit, working tree clean
```

图片会压缩后直接传进仓库的 assets 目录，文章里写相对路径就行。

> 一个文件的博客，听起来像玩具，用起来像笔记本。

## 代价

当然也有代价：

- 数据在浏览器里，换设备要导出备份
- 换文件路径等于换一个站
- 没有评论，想说话只能写信

这些我都接受。写作本来就该简单一点。
